# Nojiro (노지로)

한국의 무료 차박·노지 후보지를 비교하고 공유하기 위한 웹 프로젝트입니다.

현재 버전은 **2026년 10월 4~5일 충주 출발 → 동해안 1박 2일 무료 차박 여행**을 기준으로 제작되었습니다.

## 주요 정보

- 무료 차박 후보지 비교
- 화장실 유무 및 접근성
- 충주 출발 예상 이동시간
- 바다 접근성
- 주변 편의점·마트 접근성
- 일출·일몰 시간
- 주변 관광지 1~2곳
- 지역 및 차박 근거 등급별 필터
